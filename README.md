# Age-Calculator

## Description
A simple and interactive Age Calculator built with **Python** and **Streamlit**.  
This project allows users to input their date of birth and calculates their exact age in **years, months, and days**.  
It also displays a friendly UI with custom styling and an image banner.

## Installation
To run this project locally, install the required dependencies:
1.python -m pip install streamlit python-dateutil
2.python -m pip install python-dateutil

## Features
1.Date picker for selecting date of birth
2.Custom styled container layout with CSS
3.Image banner support (AGE.webp)
4.Exact age calculation using relativedelta
5.Displays years, months, days, and can be extended to show total days lived
